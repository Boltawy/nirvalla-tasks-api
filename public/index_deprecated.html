Everything You Need to Build

Core

Full CRUD Operations

Complete Create, Read, Update, Delete operations for tasks and task lists with clean RESTful endpoints.

Advanced

Nested Subtasks

Support for unlimited nesting levels. Build complex project structures with tasks, subtasks, and sub-subtasks.

Smart

GET /api/tasks Retrieve all tasks with optional filtering and pagination 
{ "tasks": [...], "total": 42, "page": 1 }
POST /api/tasks Create a new task with optional subtasks 
{ "title": "Complete project", "priority": "high", "dueDate": "2024-07-01", "subtasks": [...] }
PUT /api/tasks/:id Update task details or mark as completed 
{ "status": "completed", "completedAt": "2024-06-26T10:30:00Z" }
DELETE /api/tasks/:id Soft delete a task (preserves data for recovery) 
{ "message": "Task archived", "recoverable": true }
